# 配偶者控除いくら？（haigusha-ikura）

本人と配偶者の合計所得金額の場面（70歳以上の配偶者・本人の所得が900万円超・内縁・事業専従者 など）を読んで、配偶者控除・配偶者特別控除の額を当てる1日5問の学習ゲーム。正解したら「どの計算？」（配偶者控除・70歳以上の配偶者・配偶者特別控除・本人の所得で減る・受けられない）も選ぶ。

遊ぶ: <https://satou-aaaaa.github.io/haigusha-ikura/>

- 答えは、国税庁タックスアンサーの表（配偶者の合計所得金額62万円以下は配偶者控除、62万円超133万円以下は配偶者特別控除。本人の合計所得金額900万円超で減り、1,000万円超は受けられない）から出しています（［令和8年4月1日現在法令等］と、令和8年分から使う改正の注記。2026-11-17 に読みました）。民法上の配偶者でない（内縁）・青色申告者の事業専従者として給与を受けた・白色申告者の事業専従者のときも受けられません。
  - No.1191 配偶者控除 <https://www.nta.go.jp/taxes/shiraberu/taxanswer/shotoku/1191.htm>
  - No.1195 配偶者特別控除 <https://www.nta.go.jp/taxes/shiraberu/taxanswer/shotoku/1195.htm>
- 金額は令和8年分の決まりです（配偶者の所得の境目は62万円）。税額・障害者控除・年の途中の結婚や死亡・給与収入から所得への計算・申告の手続きは出しません。人と金額はつくりものです。
- このゲームは配偶者控除のしくみを知る練習です。税の相談の代わりではありません。実際の控除の額は、国税庁の資料や税務署で確かめてください。
